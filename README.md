# 🥁 节拍器 · Metronome

> **在线使用地址**：[https://moanet.github.io/Metronome/](https://moanet.github.io/Metronome/)
> *(建议使用手机或电脑 Chrome/Edge 浏览器打开，并在菜单中「添加到主屏幕」以获取最佳体验)*

一个单文件、零依赖、可离线使用的专业网页节拍器。支持 PWA 安装、多版本 BPM 管理、本地音频分析以及基于 GitHub Gist 的云端同步。

## ✨ 核心特性

### 🎵 专业级节拍
- **BPM 调节**：30–250 BPM，支持旋钮拖拽、点击输入、长按连按。
- **TAP 测速**：连续点击即可计算当前拍速。
- **拍号支持**：内置常用拍号，支持自定义分子分母。
- **拍点模式**：每一拍均可独立设置为「重音 / 次重音 / 节拍音 / 无声」。
- **拍内细分**：支持四分、八分、三连音、十六分以及各种休止位变体。
- **Swing 摇摆**：0–100% 连续调节，专为爵士/流行律动设计。
- **高精度音频**：基于 Web Audio API 调度，告别 JS 计时器抖动，内置 6 种音色。

### 🏋️ 练习辅助
- **变速练习**：设定起始 BPM 和目标 BPM，每 N 小节自动递增/递减，到点自动停止。
- **倒计时**：支持 5–30 分钟倒计时，结束时自动停止节拍器。
- **音频跟练**：导入本地音频，自动分析拍速并同步节拍器；支持首拍偏移、单曲循环和预节拍。
- **本地音频分析**：纯前端分析音频 BPM 和调性（基于 FFT 和色度特征），数据绝不上传。

### 📚 曲库管理
- 记录歌名、歌手、调性、BPM 及练习细分。
- **多版本 BPM**：一首歌可以保存多个速度版本（如 v1 原版、v2 慢练），互不覆盖。
- 标签分类、拼音首字母搜索、拖拽自定义排序。
- 回收站机制（保留 7 天），防止误删。
- 支持 JSON / TXT 批量导入导出。

### ☁️ 多设备同步（可选）
- 基于 **GitHub Gist** 的轻量云同步。填入 Token 和 Gist ID 即可在手机、平板、电脑间同步曲库。

### 📱 UI / UX
- **全平台自适应**：手机竖屏单页滑动、平板竖屏居中显示、电脑/平板横屏自动切换为三栏并排布局。
- **深色模式**：沉浸式 UI 设计。
- **PWA 支持**：支持添加到手机或电脑主屏幕，断网也可正常使用。

## 🚀 快速开始

### 在线使用
直接在浏览器中访问：[https://moanet.github.io/Metronome/](https://moanet.github.io/Metronome/)
- 手机端：通过浏览器菜单选择「添加到主屏幕」。
- 电脑端：点击地址栏右侧的「安装」图标，即可作为独立桌面应用运行。

### 本地运行
由于项目是纯单文件（包含 CSS 和 JS），你可以直接：
1. 下载 `index.html`。
2. 双击在浏览器中打开即可使用。

*(注：如果要在本地体验 PWA 或离线缓存功能，建议使用本地服务器运行，如 `npx serve` 或 VS Code 的 Live Server)*

### 部署到自己的 GitHub Pages
1. Fork 或 Clone 本仓库。
2. 在仓库的 **Settings -> Pages** 中，将 Source 设置为 `main` 分支的 `/root` 目录。
3. 等待几分钟，访问 `https://你的用户名.github.io/仓库名/` 即可。

## ☁️ 云端同步配置指南
1. 前往 GitHub 的 [Developer Settings -> Tokens (classic)](https://github.com/settings/tokens) 生成一个新 Token，勾选 **`gist`** 权限。
2. 在应用内的「曲库 -> 云端同步」中填入 Token。
3. 点击「推送到云端」，系统会自动为你创建一个私有 Gist。
4. 在其他设备上填入**相同的 Token 和 Gist ID**，点击「从云端拉取」即可完成同步。
*(注：Token 仅保存在你本机的浏览器 localStorage 中，不会上传至任何第三方服务器)*

## 🛠️ 技术栈
- 原生 HTML / CSS / JavaScript（无任何第三方框架）
- Web Audio API (音频合成与精确调度)
- Canvas (自绘旋钮与交互动效)
- Service Worker (PWA 离线缓存)
